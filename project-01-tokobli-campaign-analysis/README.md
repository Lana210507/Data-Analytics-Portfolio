# TokoBli Campaign Performance & A/B Testing Analysis

Data analytics case study evaluating e-commerce campaign performance, promotional efficiency, category performance, and a product detail page A/B test.

## Project Overview

This project analyzes TokoBli campaign transaction data across three promotional periods: 10/10, 11/11, and 12/12.

The analysis focuses on identifying campaign performance patterns, evaluating promotional efficiency, understanding category performance, and assessing whether a new product detail page improved average transaction value.

## Key Areas

- Data cleaning and preparation
- Descriptive statistics
- Campaign performance analysis
- Revenue and discount analysis
- Category analysis
- Promotional efficiency
- A/B testing
- Business recommendations

## Key Findings

- 11/11 generated the highest revenue at Rp16.62B.
- 11/11 had the highest customer count at 1,567.
- 12/12 generated the highest transaction volume at 3,414 transactions.
- 12/12 sold the highest number of units at 4,485.
- 12/12 achieved the highest revenue-to-discount ratio at 58.54.
- Men's Fashion was the strongest category across major sales metrics.
- Group B recorded an average transaction value of Rp830,460 compared with Rp746,103 for Group A.
- Group B showed an approximately 11.3% higher average transaction value, with the difference statistically significant based on the performed A/B test.
