# RevoGrocers Sales Performance Analysis

## Overview

This project analyzes sales performance across product categories using SQL.

The objective is to identify the main drivers of revenue, customer purchasing behavior, and repeat purchases.

## Business Questions

- Which product categories generate the highest revenue after discounts?
- What is the relationship between sales volume and revenue?
- Which categories have the most unique customers?
- Which categories have the highest average unit price?
- Which categories contribute the most to overall revenue?
- Which categories have the highest repeat purchase rate?

## Tools

- SQL
- Google BigQuery

## Analysis

The analysis used SQL techniques including:

- JOIN
- GROUP BY
- Aggregate functions
- COUNT(DISTINCT)
- CTEs
- Window functions

## Key Findings

- Confections generated the highest revenue after discounts.
- The top three categories were Confections, Meat, and Poultry.
- These three categories contributed 34.5% of total revenue.
- Confections had the highest customer count and repeat purchase rate.
- Grain had the highest average unit price.

## Recommendations

- Prioritize inventory and marketing for the highest-performing categories.
- Increase repeat purchases through loyalty programs and targeted promotions.
- Use bundles and cross-selling to increase sales volume in lower-performing categories.
- Maintain premium pricing for high-value categories when customer demand remains stable.
